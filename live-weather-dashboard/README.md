# Weatherly - Live Weather Dashboard

A modern responsive weather dashboard that fetches real-time weather information and a 5-day forecast using asynchronous JavaScript and the Open-Meteo API.

## 🚀 Features

- Search weather by city
- Real-time temperature
- Weather condition icons
- Weather description
- Feels-like temperature
- Humidity information
- Wind speed
- 5-day weather forecast
- Dynamic DOM rendering
- Loading state
- Search validation
- API error handling
- Responsive design
- Modern dark UI
- No API key required
