# NovaShop - Mini E-Commerce App

A polished beginner-friendly e-commerce web application built using HTML, CSS, and JavaScript.

The project demonstrates dynamic product rendering, shopping cart functionality, quantity management, total price calculation, category filtering, and a modal checkout preview.

## 🚀 Features

- Dynamic product cards
- Products generated from JavaScript objects
- Category filtering
- Add products to cart
- Increase/decrease product quantity
- Remove products automatically when quantity reaches zero
- Live cart item count
- Automatic total price calculation
- Shopping cart sidebar
- Checkout preview modal
- Responsive design
- Mobile-friendly interface
- Keyboard Escape support
- Modern SaaS-style UI
- Hover animations and transitions
